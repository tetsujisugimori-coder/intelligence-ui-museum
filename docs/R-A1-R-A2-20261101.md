- R-A1: Modalは明示的にopenerへfocusしてEnterで開く。Escape後は最大5秒の単一DOM条件待ちで、dialogの除去とopenerへのfocus復帰を同時に要求。固定sleep、blind retry、期限延長なし。pageerror収集を維持。
- R-A2: Selectの実focus / :focus-visibleに加え、本体と`::after`のcomputed outline/shadow、visibility/display/opacity、生成content、祖先の可視性、非ゼロ寸法を記録。表示された枠を検査し、無条件PASSやassert削除をしない。WCAGコントラスト適合の保証ではない。
- 同じ実runnerを起動する独立した受入harnessを追加。正常12 smoke/40 matrix、遅延モデル、閉鎖不能、枠消失/非表示、後着pageerror、cleanup失敗、プロセス期限切れを分離。
- `browser-stage-a`をCI必須ジョブへ追加。既存preservation/buildと既存25契約は維持。試験専用Playwright 1.56.1とlockfileのみ追加し、製品依存・SDKは変更しない。

`CODEX_PRIMARY_RUNTIME_NODE_MODULES=<絶対path>/tools/stage-a-browser/node_modules`を設定し、`.work/v10`で`node scripts/stage2r-browser-acceptance.cjs`。
