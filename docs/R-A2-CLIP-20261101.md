## 判定方法と範囲
スタイル設定だけではclip/overflow後の描画を証明できないため、既存`focusPaint`を診断情報として残し、実際の画素比較も必須にした。Select本体と`::after`の領域、祖先のclip-path/overflow/visibility/opacity/rectを記録する。正常なクリッピングは一律拒否せず、実画像の差で評価する。
フォーカスと`:focus-visible`を保ち、outlineとbox-shadowだけを試験用styleで一時抑止する。ON/OFF/OFF/ONの4枚を同一engine・同一条件・同一領域で比較し、finallyで抑止styleを除去する。別engine間のgolden画像比較や製品CSSの書換えは行わない。各画像と数値を保存する。
本体と、position:absolute・解決済み寸法の`::after`を個別の候補boxとして扱う。疑似要素が内側へ6px入った異なる領域も対照に含める。候補box外24 CSS pxまでを取得し、viewport内へ収める。box自体がviewport外ならUNVERIFIED。候補ごとに反復する画素差が最低`max(16, ceil((width+height)*0.5))`、横と縦の広がりが各boxの半分以上必要。これは今回の枠可視性に関する保守的な受入基準であり、部分欠損の完全検出・任意のCSS・WCAG適合を保証しない。
8階調までの同状態間の差を許し、ON/OFFの各RGB最大差24以上を反復して確認する。枠のごく低い視認性や24px外の描画はこの検証器の保証外。ピクセル不安定・未対応のtransform/filter/mask/blend/perspective・未解決の疑似要素配置は合格に含めない。祖先の任意形状clipはブラウザが最終的に描いた結果として評価する。
操作直後の有限アニメーションは最大5秒の状態条件待ちで完了を確認する。固定sleep、正常化のための無条件retry、既存deadline延長はない。PNG復号には固定Playwright 1.56.1が同梱するdecoderを使う。内部pathが将来変化・欠落すれば例外から失敗し、成功へフォールバックしない。製品・検証用package/lockは不変更。
