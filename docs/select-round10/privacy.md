# CI raw evidence privacy release gate

Scope: only new synthetic Museum trials produced in GitHub-hosted Actions may be uploaded as raw JSON, PNG and Playwright traces. The user's approval excludes physical Windows-PC evidence. Self-hosted and local runs fail this release gate. Stage 3 remains HOLD; PR remains Draft until separately accepted.

The gate requires the actual runner and auditor exits, clean commit/run/attempt provenance, 30 fresh contexts with empty storage, no external responses or blocked route requests, and an exact file manifest. URLs for navigation and captured network requests must use canonical loopback hosts and fixed public test query values. Authentication/cookie headers, unknown headers, bodies, storage state, credential-shaped JSON fields and common secret/personal-data patterns block release. Unknown files, symlinks, unsafe ZIP paths, encrypted ZIP entries, oversized entries, unrelated resources and changed source attachments also block release. Network response resources must byte-match the local Museum build. The source product/archive remains pinned to the preserved reviewed baseline.

Public-source review: apps/v10/src/main.tsx renders six fixed teaching components and synthetic controls; index.html has a restrictive CSP, no authenticated host integration and no personal data inputs. The preserved v09 viewer is local teaching content. Public source links and CSP-blocked CDN font URL literals are not network authorization. The one public dictionary label `Password:'表示・非表示を切り替える。'` and Playwright-generated page image IDs are narrowly exempted from textual false positives, not arbitrary credentials.

PNG metadata chunks outside the encoder allowlist are refused. Screenshots and trace frames are admitted based on fresh synthetic context, fixed public source/build, local-only traffic, exact manifest and producer provenance. Regex does **not** prove that arbitrary pixels are free of private information; there is no OCR claim. This gate is not permission to upload screenshots from a personal browser or machine. If provenance is missing or evidence is unfamiliar, raw upload stops rather than guessing.

Only a successful runner, independent raw auditor and privacy gate enable the raw artifact step. Failure retains only the allowlisted diagnostic summaries and hash/exit records, not raw logs, images or traces. Automated negative controls contain synthetic strings and must not print candidate secret values. Keep user-facing reports free of raw private paths or values.
